# JEO Research | Jason Orlosky, PhD

This repository powers the GitHub Pages website for [JEO Research](https://www.jeoresearch.com/), the research and educational site of [Jason Orlosky, PhD](https://www.jeoresearch.com/aboutme.html).

Jason Orlosky is an associate professor, researcher, educator, and open-source developer working in eye tracking, augmented reality, virtual reality, artificial intelligence, human-computer interaction, gaze interaction, and accessible research tools.

## Site topics

The JEO Research website includes tutorials, publications, lab pages, and project documentation related to:

- DIY eye tracking and low-cost gaze tracking systems
- Eye tracking for augmented reality, virtual reality, and mixed reality
- Gaze interaction, head gaze, and computer vision interfaces
- Infrared safety considerations for eye tracking hardware
- XR research, intelligent agents, and human-computer interaction
- Open-source educational software and research tools
